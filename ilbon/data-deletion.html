앱: 일본어 한입 - JLPT·여행 일본어 (Android, 패키지 com.ilbon.jp) · 개발자: 유씨넷 (Ucnet)

먼저 알아 두세요
  • 이 앱에는 회원가입·로그인이 없어 삭제할 "계정"이 없습니다.
  • 학습 기록은 이용자 기기 안에만 저장되며, 개발자는 별도 서버를 운영하지 않습니다.
  • 쉐도잉 발음 확인에 쓰인 음성은 녹음 파일로 저장하지 않습니다.

1. 기기에 저장된 데이터 지우기 (바로 삭제)

학습 진도, 복습 일정, 단어장, 퀴즈·에피소드 기록, 앱 설정, 구매 확인 정보가 삭제됩니다.

  1. 휴대폰 설정 → 애플리케이션(앱) → 일본어 한입을 엽니다.
  2. 저장공간 → 데이터 삭제를 누릅니다. 또는 앱을 제거합니다.

구매한 팩은 Google Play 계정에 기록되어 있어, 같은 Google 계정으로 다시 설치하면 자동으로 다시 열립니다. 구매 내역 자체는 Google Play가 보관합니다.

2. Google 계정 백업 지우기

Android 자동 백업을 켜 두었다면 학습 기록 사본이 이용자의 Google 계정 백업 공간에 있을 수 있습니다.

  1. Google Drive 앱(또는 drive.google.com)에서 저장용량 → 백업으로 갑니다.
  2. 해당 기기의 백업을 열어 앱 데이터를 삭제하거나, 휴대폰 설정에서 백업을 끕니다.

3. 개발자에게 삭제 요청하기

사용 통계·광고 처리 데이터의 삭제를 원하거나, 위 방법으로 해결되지 않으면 아래 이메일로 요청해 주세요.

받는 곳: chfhddl515@gmail.com
제목: [일본어 한입] 데이터 삭제 요청

  1. 본문에 삭제를 원하는 항목(사용 통계, 광고 등)과 사용 중인 기기 모델을 적어 주세요.
  2. 요청을 받은 날부터 10일 이내에 처리 결과를 회신합니다.
  3. 개발자는 이용자를 식별하는 정보를 갖고 있지 않으므로, 확인이 필요한 경우 추가 정보를 요청할 수 있습니다.
